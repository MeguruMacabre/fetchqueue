# FetchQueue

**FetchQueue** - позволяет организовать параллельную загрузку файлов с хранением их состояния в БД и восстановлением в случае ошибок или принудительной остановки.

## Установка и запуск

Для сборки требуется Go 1.25 или новее.

```bash
git clone https://github.com/MeguruMacabre/fetchqueue.git
cd fetchqueue
```

Сборка:

```bash
go build -o fetchqueue ./cmd
```

Запуск:

```bash
./fetchqueue
```

```text
FetchQueue v0.1.0
Type help for available commands.

fetchqueue>
```

## Команды

| Команда | Описание |
|---|---|
| `add <url> [filename]` | Добавить файл в очередь |
| `list` | Показать все загрузки и их состояния |
| `start` | Запустить ожидающие загрузки |
| `resume` | Продолжить приостановленные загрузки |
| `retry` | Повторить неудачные загрузки |
| `workers [count]` | Посмотреть или изменить количество воркеров (1–32) |
| `delete <id>` | Удалить загрузку и её файл |
| `clear` | Очистить очередь и удалить загруженные файлы |
| `help` | Показать справку |
| `exit` | Завершить программу |

## Технологии

- Go
- SQLite
- HTTP / HTTP Range
- Goroutines, Channels, Context
- Worker Pool

## Как это работает

- Задачи добавляются через CLI и сохраняются в SQLite.
- Загрузки выполняются параллельно с помощью Worker Pool (горутины и каналы).
- Состояние загрузок и количество скачанных байт сохраняются в БД.
- При остановке через Ctrl+C загрузки приостанавливаются.
- Возобновление выполняется через HTTP Range без повторного скачивания уже полученных данных, если сервер поддерживает частичные запросы.

## Хранение данных

Все данные хранятся рядом с исполняемым файлом:

- `fetchqueue.db` — SQLite-база данных.
- `downloads/` — папка с загруженными и частично загруженными файлами.
